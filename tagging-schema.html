Overview

Controlled Vocabulary Schema for Adventist Historical Literature


This controlled vocabulary provides a hierarchical tagging schema for organizing academic literature in history and related disciplines focusing on Seventh-day Adventism and associated religious groups.

Guiding principles

Start broad, then refine

Use high-level tags at first, and add more specific ones as patterns emerge.

Use multiple descriptors

Most items get several tags: period, geography, topic, and sometimes method or people.

Add new subtags sparingly

Create a new subtag only when 3 or more items need it.

Keep it organized

Tags are written as short paths separated by ::. For example, Geography::North America::United States reads like a breadcrumb trail.
